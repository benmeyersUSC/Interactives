The bottom row sweeps the upper limit of each integral from left to right, so each curve shows area accumulating. The first two accumulate f and the shifted g on their own — note that the second one's final height never changes as you scrub, only its position does, since shifting a function doesn't change its total area. Only the third one, which accumulates the product, has an endpoint that moves: that endpoint is exactly (f ∗ g)(x), the dot riding the purple curve above.
